# كاشير الكافيه ☕

تطبيق إدارة كافيه (نقطة بيع) بواجهة Neumorphic بيضاء — يعمل بدون إنترنت، وجاهز للتحويل إلى APK عبر Capacitor.

## المميزات
- الرئيسية: مبيعات اليوم / المصروفات / الطلبات المفتوحة + البيع السريع + الترابيزات + باقي الأقسام
- البيع السريع: أقسام تضيفها وتمسحها بنفسك + إضافة أصناف + إنشاء فاتورة بسرعة
- الترابيزات: إنشاء ترابيزة، تسجيل الطلبات، إصدار فاتورة الحساب
- المنتجات: سعر البيع + سعر الشراء (اختياري للأرباح)
- المصروفات: أسباب قابلة للإضافة، نقدي / أجل (مع اسم الدائن) وسداد الأجل
- الخزنة: رصيد افتتاحي + إيداع/سحب + المبيعات والمصروفات تلقائياً
- التقارير: يوم / أسبوع / شهر / سنة + جرد المنتجات المباعة
- سجل الفواتير
- تبديل البائع: وضع بائع على هاتف العامل (بيع + فواتير فقط) ومزامنة مباشرة مع المالك
- الإعدادات: اسم الكافيه، الألوان، رمز المالك، نسخ احتياطي/استرجاع، ضبط المصنع

## بناء الـ APK (الطريقة الأسهل — GitHub Actions)
1. ارفع كل الملفات على مستودع GitHub (فرع `main`).
2. تبويب **Actions** ← **Build APK** ← انتظر انتهاء البناء.
3. حمّل الملف `cafe-pos-apk` من الـ Artifacts وثبّته على الهاتف.

## بناء الـ APK على جهازك
```bash
npm install
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug
# الناتج: android/app/build/outputs/apk/debug/app-debug.apk
```

## تبديل البائع (المزامنة)
1. على هاتف العامل: الإعدادات ← تحويل الجهاز لوضع البائع.
2. شغّل الهوت سبوت من أحد الهاتفين واربط الآخر به.
3. المالك: تبديل البائع ← اكتب كود الاتصال ← إنشاء رمز نقطة الاتصال ← أرسله للعامل.
4. العامل: الاتصال بالمالك ← يكتب الكود ويلصق الرمز ← اتصال ← يرسل الرد للمالك.
5. المالك يلصق الرد ← ربط. بعدها: «إرسال المنتجات للعامل» أو «سحب المبيعات» ثم «إغلاق نقطة الاتصال».
- مبيعات العامل تظهر في «مبيعات الفرد الثاني» وتُضم تلقائياً للخزنة والتقارير، ولا تتكرر لو اتسحبت مرتين.
- لو الاتصال المباشر مش اشتغل على شبكة معينة: استخدم «البديل بالنص» (نسخ/لصق عبر واتساب).

## ملاحظة
البيانات محفوظة داخل الجهاز. خد نسخة احتياطية بشكل دوري من الإعدادات.

## التخزين (SQLite على الهاتف)
- قاعدة البيانات **SQLite حقيقية** داخل ذاكرة الهاتف (عبر `@capacitor-community/sqlite`) وليس في المتصفح.
- يُحفظ تلقائياً (بعد ثوانٍ من أي تغيير) **نسخة كاملة في مجلد ظاهر**: `Documents/CafePOS/cafe_pos_backup.json`
  (وإن رفض الأندرويد الكتابة هناك يستخدم `Android/data/com.cafe.pos/files/CafePOS`).
- لو اتمسح التطبيق وتثبّت من جديد (أو القاعدة فاضية) يسترجع بياناته تلقائياً من المجلد.
- من الإعدادات ← التخزين: «حفظ نسخة الآن» و«استرجاع من المجلد».
- ملف قاعدة SQLite نفسه يظل في مساحة التطبيق الخاصة (الأندرويد لا يسمح بوضعه في مجلد عام بشكل آمن)، والنسخة في المجلد هي اللي تظل معاك.

## الألوان
الإعدادات ← الألوان والمظهر: أنماط جاهزة (أبيض، دافئ، أخضر، بنفسجي، ليلي) + تعديل كل لون على حدة
(الخلفية، المستطيلات، الحواف، النصوص، الأزرار، الربح، المصروف/الحذف، لون الظل الغامق والفاتح) + قوة البروز واستدارة الحواف.

## ظهور الموظفين تلقائياً (جديد)
بجانب الطريقة اليدوية (نسخ/لصق الرمز) أُضيف اكتشاف تلقائي على نفس الشبكة:
1. **الموظف:** افتح «الاتصال بالمالك» (يظهر اسمك للمالك تلقائياً) واكتب كود الاتصال.
2. **المالك:** «تبديل البائع» ← اكتب كود الاتصال ← **فتح نقطة الاتصال وإظهار الموظفين**.
3. تظهر أسماء الموظفين في قائمة؛ اضغط **اتصال** بجوار الاسم، فيتم تبادل الرموز لوحده ويُتحقق من الكود.
4. بعدها: «إرسال المنتجات» / «سحب المبيعات» ثم «إغلاق نقطة الاتصال».

ملاحظات:
- الاتصال بموظف واحد في المرة؛ أغلق الاتصال ثم اتصل بالموظف التالي.
- يعتمد على إضافة `capacitor-udp-socket` وصلاحيات الشبكة (تُضاف تلقائياً في GitHub Actions).
- بعض شبكات الواي فاي/الهوت سبوت تمنع الأجهزة من رؤية بعضها؛ وقتها استخدم «طريقة يدوية (احتياطي)» وهي تعمل كما كانت.
- المشروع الآن على Capacitor 7 (يتطلب Java 21 في البناء، وقد حُدّث ملف الـ workflow).

## التفعيل (جديد)
- أول تشغيل: التطبيق مقفول ولا يعمل إلا بكود تفعيل (شاشة «ادخل كود التفعيل»).
- كود البداية يشغّل **24 ساعة** بعدّاد ظاهر في الرئيسية؛ بعد انتهائها تظهر شاشة طلب الكود من جديد. **كل الأكواد تعمل دائماً ويمكن استخدامها أي عدد من المرات.**
- في شاشة التفعيل زر أحمر «طريقة التفعيل» يعرض تعليمات الاشتراك النهائي (٣٠٠ ج) ورقم الدفع وأيقونة واتساب.
- أكواد التمديد تُضاف على الوقت المتبقي (أو من لحظة الإدخال لو انتهى الوقت): يوم / 72 ساعة / أسبوع / شهر. وفيه كود للتفعيل النهائي.
- خانة إدخال الكود موجودة أيضاً في **الإعدادات ← التفعيل**.
- الأكواد وكلمة السر محفوظة كبصمات SHA-256 داخل `www/js/license.js` (لا تظهر كنص).
- الحماية من تأخير ساعة الهاتف: التطبيق يتذكر آخر وقت شاهده ولا يقبل الرجوع للخلف.
- ضبط المصنع والاسترجاع من نسخة احتياطية لا يلغيان حالة التفعيل.

## النسخ الاحتياطي (محمي بكلمة سر)
حفظ نسخة في المجلد، الاسترجاع من المجلد، مشاركة نسخة، والاسترجاع من ملف — كلها تطلب كلمة سر. معلومات قاعدة البيانات ومسار المجلد مخفية من الإعدادات.

## بيانات المطور
في الإعدادات: الاسم، الدراسة، وزر واتساب يفتح محادثة مع الرقم.
